Conversor de Dólares a Lempiras

Estudiante: David Josué Pallares Torres - 0101200100746
Aplicación web desarrollada con React y Vite que convierte dólares estadounidenses (USD) a lempiras hondureños (HNL). Obtiene la tasa de cambio mediante la API pública de ExchangeRate-API y calcula el resultado automáticamente.

1. Primero debera Clonar el repositorio.
2. luego de haber clonado el repositorio debera Instalar las dependencias:
   npm install
3. luego ya podremos Ejecutar el proyecto o bien con:
   npm run dev

o directamente con el enlace de Vercel

4. Abrir en el navegador la dirección que muestra la terminal en caso de utilizarlo con "npm run dev".

Esta fue la API asignada:
https://open.er-api.com/v6/latest/USD


Rates By Exchange Rate API: https://www.exchangerate-api.com
